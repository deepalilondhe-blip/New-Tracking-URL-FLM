WHAT WAS IMPLEMENTED
================================================================================

A completely INDEPENDENT automation script that:
1. Validates "Test Only" conversion records in Cake CRM
2. Extracts test user information from Unique ID records
3. Verifies against expected test user credentials
4. Automatically notifies developers of mismatches
5. Generates detailed JSON reports and logs
6. Captures screenshots for audit trail

================================================================================
TROUBLESHOOTING
================================================================================

ISSUE: Browser won't launch
SOLUTION:
├─ Ensure Chrome/Chromium installed
├─ Try without --headed flag (headless mode)
└─ Check system resources

ISSUE: Navigation fails
SOLUTION:
├─ Verify Cake URL and login
├─ Check internet connection
└─ Verify authentication state exists

ISSUE: Filter not applied
SOLUTION:
├─ Check CSS selectors match current UI
├─ Verify filter checkbox visible
└─ May need selector update if Cake UI changed

ISSUE: Email not sent
SOLUTION:
├─ Verify EMAIL_USER and EMAIL_PASS in .env
├─ Use Gmail App Password (not regular password)
└─ Check spam/junk folder

ISSUE: No records found
SOLUTION:
├─ Check date range (should be yesterday-today)
├─ Verify Test Only filter applied
└─ Check if test records exist for date range
