📌 Project Overview & Context

This document establishes the QA Tester Scope of Work for the front-end accessibility remediation of the GlobeWest Australian (AU) store. The objective is to verify all remediation fixes based on the WCAG 2.2 Level AA Audit Report.

Strategic Goal: Achieve full compliance on the AU site before the US store fork in Phase 2, preventing duplicated front-end accessibility development cycles.

🔍 Verification Rules & Accessibility Criteria

Remediation Pillar ✓ Pass Condition ✗ Fail Condition
Color Contrast
WCAG 1.4.3		 Text & UI elements must hit contrast ratios of:
  • 4.5:1 for normal text
  • 3.0:1 for large text / UI elements
 Headers, buttons, inputs, ETA spans, or footer text failing contrast checker tools.
ARIA & Labels
WCAG 1.1.1 / 4.1.2		 Discernible text name or aria-label attribute describing all interactive controls. Empty links, buttons with SVG icons only and no label text.
Touch Target Sizing
WCAG 2.5.8		 All tap targets must have size/spacing of at least 44x44px. Small mobile swatches, header navigation icons, or carousel links under 44px.
Viewport & Zoom
WCAG 1.4.4		 Users must be able to pinch-to-zoom on mobile devices. Meta tags using user-scalable=no or setting max/min scales.
Carousel HTML DOM
WCAG 1.3.1 / 4.1.1		 Clean semantic layouts where list containers only enclose list items. Slick/Swiper templates inserting direct div children within ul lists.

⌨️ Keyboard Navigation & Focus Rules

  • Logical Sequence: Tab progression must follow a logical top-to-bottom, left-to-right visual layout order.
  • Visual Focus Outlines: Every interactive element must display a high-contrast visual outline when focused.
  • Focus Trap Handling: During active modal drawers (minicart, mobile nav, PLP filters, login drawer), focus must be locked inside the overlay. Pressing tab should cycle inside and not jump behind the background overlay.

📋 Page Templates In-Scope

  • Homepage: Banners, promo widgets, main nav header.
  • Listing Page (PLP): Filter checkboxes, grids, sorting dropdowns.
  • Detail Page (PDP): Swatches, galleries, zoom, sizes, reviews.
  • Search Results Page: Autocomplete panels, results grids.
  • Checkout Journey: Cart forms, minicart, billing inputs.
  • My Account Area: Customer dashboards, address books.
  • B2B Trade Portal: Multi-step registrations, pricing grids.
  • Static Pages: Showrooms, FAQs, Contact forms.

🐛 Common QA Troubleshooting

Observed QA Failure Verification & Remediation Fix
No focus outline on buttons/links Verify outline is visible. Ensure focus styles are not disabled via outline: none.
a:focus { outline: 3px solid #e0533c !important; outline-offset: 2px; }
Tab focus escapes active modal drawer Verify keyboard tab navigation is trapped. Ensure Javascript modal libraries catch keydown events and loop focus back to drawer elements.
Screen reader skips icon buttons Ensure SVGs and icon-only anchors specify clear aria-label values (e.g. aria-label="Search") to describe functionality.
Mobile pinch-to-zoom is locked Verify mobile zoom behavior. Remove user-scalable limitations from layout viewport headers:
<meta name="viewport" content="width=device-width, initial-scale=1.0">
