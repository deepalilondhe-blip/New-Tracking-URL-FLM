================================================================================
🐧 LEADS AUTOMATION - LINUX RUN COMMANDS & SERVER SETUP GUIDE
================================================================================

This document contains all essential Linux terminal commands, batch scheduler options,
individual campaign runners, and server deployment instructions.

--------------------------------------------------------------------------------
📌 1. QUICK START COMMANDS (LINUX TERMINAL)
--------------------------------------------------------------------------------

1. Run Full Batch Once (Direct Node):
   👉 node scheduler.js --once

2. Run Full Batch in Background with Real-Time Log File:
   👉 ./run-linux-scheduler.sh

3. Run Full Batch Once (same command used by cron):
   👉 node scheduler.js

4. Run Specific Campaigns Only (Filter):
   👉 node scheduler.js --once --campaigns ftd-x,fsi-ppc2,tra-list

5. Run Headless (No GUI / Silent Mode):
   👉 node scheduler.js --once --headless

6. Send Daily Summary Email Report Manually:
   👉 node scheduler.js --email-only

--------------------------------------------------------------------------------
📌 2. INDIVIDUAL CAMPAIGN RUNNER TEMPLATE
--------------------------------------------------------------------------------

To test or execute any individual campaign on Linux:

   👉 node run-master.js --campaign <campaign-id> --viewport <desktop|tablet|mobile>

Add '--headless' if you do not want a browser window to open on your desktop:
   👉 node run-master.js --campaign <campaign-id> --viewport desktop --headless

⚠️ 4. IMPORTANT: LAPTOP POWER OFF vs. CLOUD SERVER EXPLAINED
--------------------------------------------------------------------------------

🔴 IF YOUR LAPTOP IS COMPLETELY POWERED OFF (SHUTDOWN):
   - NO local script or cron job can run on the laptop because the CPU, RAM,
     and Operating System are completely turned off.
   - To run scripts when your laptop is turned OFF, the code MUST be deployed
     on a Cloud Server / VPS (AWS, DigitalOcean, Linode, HostGator, etc.).

🟢 IF YOUR LAPTOP IS POWERED ON BUT SCREEN IS LOCKED / DISPLAY OFF:
   - The scheduler CAN run in the background!
   - Just make sure your system sleep/suspend is disabled when plugged in.

☁️ 5. HOW TO RUN ON A REMOTE SERVER (24/7 AUTOMATION)
--------------------------------------------------------------------------------

When deployed to a remote Linux Cloud Server, it will run independently 24/7
even when your laptop is at home and switched OFF.

### Step 1: Install Server Dependencies (Run once on the Server)
sudo apt-get update
sudo apt-get install -y wget curl git cron ca-certificates \
  libnss3 libnspr4 libatk1.0-0t64 libatk-bridge2.0-0t64 libcups2t64 \
  libdrm2 libxkbcommon0 libxcomposite1 libxdamage1 libxfixes3 libxrandr2 \
  libgbm1 libpango-1.0-0 libcairo2 libasound2t64 xvfb

### Step 2: Clone Code & Install Node Modules on the Server
git clone <your-repo-url>
cd "New Tracking URL"
npm install
export PLAYWRIGHT_HOST_PLATFORM_OVERRIDE="ubuntu24.04-x64"
npx playwright install chromium

### Step 3: Copy Configuration Files
Copy your .env and service_account.json to the server project folder.

### Step 4: Schedule Runs via Server Crontab
Run: crontab -e
Add your morning & afternoon schedule (e.g. 10:00 AM & 3:00 PM IST):

CRON_TZ=Asia/Kolkata
0 10 * * 1,3,5 /home/ubuntu/New-Tracking-URL/run-linux-scheduler.sh
0 15 * * 1,3,5 /home/ubuntu/New-Tracking-URL/run-linux-scheduler.sh

### Step 5: (Alternative) Run 24/7 Background Daemon with PM2
npm install -g pm2
pm2 start scheduler.js --name "flm-leads-scheduler"
pm2 startup
pm2 save
